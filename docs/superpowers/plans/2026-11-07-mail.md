# Mail in MyNotion, with Aria — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Gmail inbox (Primary only, no ads/newsletters/spam) inside MyNotion, readable and answerable by voice through Aria.

**Architecture:** MyNotion's Electron main process syncs Gmail over IMAP into new tables in `noted.db` and sends over
SMTP through an outbox table. The Angular app gets an Inbox section. Aria's new `Engines/MailEngine.py` reads those
tables, and talks to Gmail itself (imaplib/smtplib) to send, archive, and check when MyNotion isn't syncing.
The app password lives in the system keyring (Secret Service).

**Tech Stack:** Electron + TypeScript (`imapflow`, `nodemailer`, `mailparser`, `@napi-rs/keyring`, `vitest` for tests),
Angular 20, Python 3.12 (`imaplib`, `smtplib`, `email`, `secretstorage`), pytest.

**Spec:** `MyNotion/docs/superpowers/specs/2026-11-07-mail-design.md`

Repos: MyNotion = `/home/lala/Desktop/school/personal/MyNotion` (paths below start with `note/` or `note-frontend/`),
BetterAI = `/home/lala/Desktop/school/personal/personal-ai/BetterAI` (paths start with `Engines/`, `tests/`, `main.py`).

## Global Constraints

- No Google Cloud project / OAuth. Gmail via IMAP (imap.gmail.com:993, TLS) and SMTP (smtp.gmail.com:465, TLS) with an app password.
- The password is stored only in the keyring: service `MyNotion Mail`, account = the Gmail address. Never in `noted.db`, a file, or a log.
- Inbox shows only Gmail's Primary category: IMAP search `X-GM-RAW "category:primary"` in INBOX. Spam folder never read.
- First sync: last 3 months, newest first. Sync every 2 minutes and on refresh.
- Nothing is sent without an explicit yes (Aria) or the Send button (MyNotion). Aria's outbox waits 10 s before sending, so "undo" works.
- Never delete mail; archive = remove the INBOX label (stays in All Mail).
- MyNotion keeps its current dark/green look (`#1f2233` panels, `#4ade80` accent), existing component CSS patterns.
- Commit only when Lala asks (user rule): the "Commit" steps below are checkpoints to stage and show, not to run `git commit` unprompted.
- Keep `BetterAI/FEATURES.md` and the MyNotion README updated with what's added.

## Review Focus

1. A mail with no subject, an odd charset, or only HTML → list shows "(no subject)" and a readable text preview (Task 3 test `parses_awkward_messages`).
2. Gmail resets UIDVALIDITY → the next sync refetches the window instead of skipping or duplicating (Task 3 test `uidvalidity_change_resyncs`).
3. The connection drops mid-sync → rerunning adds no duplicates (unique `gm_msgid`; Task 3 test `rerun_adds_no_duplicates`).
4. Replying to a mail without a Message-ID header → reply still sends, just unthreaded (Task 4 test `reply_without_message_id`).
5. "Read the one from Sara" with two Saras, or none → Aria asks which / says she found none, never picks silently (Task 7 test `ambiguous_or_missing_sender`).
